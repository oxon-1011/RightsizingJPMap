# 出典の表示

RightsizingJPMap が使うデータの利用条件と、出典の表示の書き方をまとめる。
利用条件は、2026-11-07 に各提供元の公式のページで確かめた。
確かめたページは、この文書の最後の「確かめたページ」に載せる。

## 利用条件のまとめ

| 提供元 | 使うデータ | 利用条件 | 出典の表示 | 加工の表示 |
|---|---|---|---|---|
| 国土交通省（国土数値情報） | 1kmメッシュ別将来推計人口（R6国政局推計）、行政区域データ（2024 年） | オープンデータ（CC BY 4.0）。国土数値情報ダウンロードサイトコンテンツ利用規約（政府標準利用規約準拠版） | 要る | 要る |
| 国立社会保障・人口問題研究所 | 日本の地域別将来推計人口（令和5年推計）と参考資料 | 公共データ利用規約（第1.0版）（PDL1.0）に準拠 | 要る | 要る |
| 国土地理院 | 最適化ベクトルタイル（試験公開） | 国土地理院コンテンツ利用規約。権利表記のないものは PDL1.0 | 要る | 要る（加工にあたるかは書かれていないが、添える） |

どの利用条件も、複製、加工、再配布、商用の利用を認め、出典を示すことを求めている。
加工したものを公表するときは、出典とは別に加工したことを書き、国や各機関が作ったかのように見せてはならない。
PDL1.0 は、デジタル庁のページで、クリエイティブ・コモンズの表示 4.0 国際（CC BY 4.0）と互換性があるとされている。
国土数値情報の利用規約も、CC BY 互換であると書いている。

このアプリは、どのデータも集計や形式の変換をしてから配信するので、出典に加えて加工の表示をする。

## 国土数値情報（国土交通省）

1kmメッシュ別将来推計人口と行政区域データの製品のページは、どちらも使用許諾の条件を「オープンデータ（CC BY 4.0）」とし、国土数値情報ダウンロードサイトコンテンツ利用規約（政府標準利用規約準拠版）にリンクしている。
この利用規約は、複製、公衆送信、翻案などの利用を認め、商用の利用もできるとしている。

利用規約の出典の記載例は、「出典：「国土数値情報（○○データ）」（国土交通省）（当該ページのURL）」の形である。
加工した場合は、これとは別に「〜を加工して作成」と書く。

このアプリでの表示は、次のようにする。

```
「国土数値情報（1kmメッシュ別将来推計人口（R6国政局推計））」（国土交通省）
（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-mesh1000r6.html）を加工して作成

「国土数値情報（行政区域データ）」（国土交通省）
（https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2024.html）を加工して作成
```

1kmメッシュの推計の製品のページは、原典資料として、総務省の令和2年国勢調査と、社人研の全国と地域別の将来推計を挙げている。
原典資料について別の出典の表示を求める記載は、このページにはなかった。

行政区域データの製品のページには、「測量法に基づく国土地理院長承認（複製）R 5JHf 357」という承認番号が書かれている。
この番号を、加工したデータの側にも書く必要があるかは、ページからは判断できなかった。
詳しい出典の表示には、この番号も添える案にする。

## 国立社会保障・人口問題研究所

社人研のサイトのご利用のページは、特記のない限りコンテンツの権利は社人研に帰属し、権利表記のない限り PDL1.0 に準拠した条件で利用できるとしている。
地域別将来推計人口の推計のページには、別の権利表記は見当たらなかった。
配布されている Excel のファイルの中に権利表記があるかは、確かめていない。

サイトのご利用のページの出典の記載例は、「出典：「日本の将来推計人口（平成29年推計）」（国立社会保障・人口問題研究所）（URL）」の形である。
加工した場合は、これとは別に「〜を加工して作成」と書く。

このアプリでの表示は、次のようにする。
浜松市の3区の参考資料は、同じ推計のページで公表されているので、まとめて書く。

```
「日本の地域別将来推計人口（令和5年推計）」（国立社会保障・人口問題研究所）
（https://www.ipss.go.jp/pp-shicyoson/j/shicyoson23/t-page.asp）を加工して作成
```

社人研のサイトは、リンクは許可なく貼ってよいが、できるだけトップページに貼るよう求めている。
トップページ以外に貼る場合は、出所を明記するよう求めている。
上の表示は、出所（社人研と推計の名前）を書いたうえで推計のページにリンクする。

## 国土地理院

背景の地図には、国土地理院の最適化ベクトルタイルを使う。
GitHub のリポジトリ（gsi-cyberjapan/optimal_bvmap）の説明によると、このタイルは試験公開のデータで、2022 年 9 月 6 日から公開終了までの期間に公開される。
URL、データの構造、属性は変わることがある。

国土地理院コンテンツ利用規約は、権利表記のないコンテンツに PDL1.0 を適用し、出典の記載を求めている。
最適化ベクトルタイルのリポジトリの説明は、出典として「国土地理院最適化ベクトルタイル」などと明示するよう求めている。

地理院タイル一覧のページは、地理院タイルをウェブサイトやアプリでリアルタイムに読み込んで使う場合、出典を示すだけで申請なく使えるとしている。
出典には「国土地理院」や「地理院タイル」などと書き、一覧のページへのリンクを付けるよう求めている。
一覧のページには最適化ベクトルタイルが載っていないので、この記述が当てはまるかは書かれていない。
リポジトリの説明は、最適化ベクトルタイルを基本測量成果とは位置付けていないとしている。
このアプリはタイルをリアルタイムに読み込むので、申請は要らないと判断し、一覧のページへのリンクも添える。

地図の上の出典の表示は、次のようにする。

```
国土地理院最適化ベクトルタイル（https://maps.gsi.go.jp/development/ichiran.html）
```

このアプリは、最適化ベクトルタイルに独自のスタイルを当てて描く。
スタイルを変えて描くことが、利用規約の「編集・加工」にあたるかは、利用規約にもリポジトリの説明にも書かれていなかった。
加工にあたるとすれば、国土地理院が作ったかのように見せない限り、加工の表示を添えれば使える。
どちらとも書かれていないので、加工にあたるものとして扱い、詳しい出典の表示に次の文を添える（2026-11-09 に決めた）。

```
「国土地理院最適化ベクトルタイル」（国土地理院）（https://github.com/gsi-cyberjapan/optimal_bvmap）を加工して作成
```

## 画面での表示

地図の右下に、提供元の名前を短く並べ、詳しい出典の表示へのリンクを置く。

```
国土地理院最適化ベクトルタイル | 国土数値情報（国土交通省） | 国立社会保障・人口問題研究所 | 出典の詳細
```

「出典の詳細」は、この文書へのリンクである。
この文書の各節に示した「〜を加工して作成」の文と、行政区域データの承認番号を、詳しい出典の表示とする。
生成物を GitHub Release などで配布するときも、同じ表示を添える。
