# 利用者向けの文書

RightsizingJPMap を使う人に向けた文書を置く（D16）。
読み手には、自治体の職員など、地図でデータを見比べたい人を想定している。

## 文書の一覧

| 文書 | 内容 |
|---|---|
| [usage.md](usage.md) | 使い方。画面の構成、指標と年次の切り替え、地図の上の値の見方、背景地図の設定、自前データの追加と削除、場所への移動、接続する外部のサーバー |
| [acceptance.md](acceptance.md) | 取り込めるデータの条件。CSV、Parquet、GeoJSON の条件、拒否される例と直し方、ほかの形式からの変換 |
| [data-sources.md](data-sources.md) | データの出典と注意事項。推計値であること、透明なメッシュ、年次の範囲、浜通り地域、浜松市の区 |
| [attribution.md](attribution.md) | 出典の表示。各提供元の利用条件と、表示の書き方 |
