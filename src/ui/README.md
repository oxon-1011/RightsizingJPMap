# ui

React のコンポーネントとスタイルを置く層。
部品は状態を持たず、表示する値と操作の関数を props で受け取る。
ただし、色の候補の開閉のように、その部品の中で閉じる表示の状態は部品が持つ。
状態は app のストアが持ち、`App.tsx` がストアの値と app の手続きを部品につなぐ。
書き方は [docs/guides/coding.md](../../docs/guides/coding.md) に従う。

## 部品の一覧

画面の構成は [docs/design/ui.md](../../docs/design/ui.md) と、Figma のページ「人口縮減」の画面 01〜04 に合わせている。

| `BasemapSettings.tsx` | 左上のパネルの歯車と、背景地図の鉄道、道路、川の表示を切り替える設定 | なし |

右下の出典は、MapLibre の AttributionControl が出す（`src/io/map.ts`）。

`App.tsx` は、画面全体に地図を広げ、その上に部品を重ねる。
値と操作のつなぎ方は、`src/app/README.md` の「段階 7 での使い方」のとおりである。
部品には重なりの順（`z-10` など）を付けている。
付けないと、地図の操作の部品と出典（MapLibre の CSS で `z-index: 2`）が部品の上に重なる。

## 部品から切り出した処理

部品の中の判断は、純粋な関数に切り出して node のテストで確かめる。

| ファイル | 内容 |
|---|---|
| `legend-format.ts` | 凡例の目盛りの数字と、スクリーンリーダー向けの階級の範囲 |
| `year-slider.ts` | スライダーの位置と年の変換、キーで動かしたあとの年 |
| `indicator-options.ts` | 指標と分母のセレクトボックスの選択肢 |
| `notice-text.ts` | 通知の文言。取り込めなかった理由と、行や地物の番号 |
| `keyboard.ts` | Ctrl + K の判定と、候補の一覧のキー操作 |
| `file-drag.ts` | ファイルを重ねているかの判定 |
| `layer-color.ts` | レイヤーの色の候補（core の `LAYER_COLORS`）の、読み上げる名前 |
| `hover-format.ts` | ホバーのカードの見出しと行の文字、カードの置き場所 |

## ホバーのカード

`HoverCard.tsx` は、ポインタの横に白いカードを出す。
ポインタの操作は受けず（`pointer-events-none`）、クリックでの固定とキーボードでの操作は足さない（D27）。

- **書き方**：指標の値は、凡例の目盛りと同じ書き方（`legend-format.ts` の `formatLegendValue`）に、範囲の文と同じ単位（「人」「%」）を付ける。増減率は、凡例と同じく正の数に + を付ける。2行目の人数（総人口か、人口あたりの値の分母）は、整数に丸めて全部の桁を出し、「万」は使わない（`formatHeadcount`。「1,283 人」「60,000 人」）。指標が総人口のときの1行も、同じ書き方にする。秘匿は「秘匿」、値なしは凡例と同じ「なし」にする。
- **行**：メッシュと市区町村では、指標の値と、その年の2行目の人数の2行にする。2行目はふだん総人口で、人口あたりの値の分母が総人口でなければ、その分母の人数にする（「65歳以上人口 1,234 人」）。指標が総人口なら1行にする。結合した指標で人口あたりの値を選んでいるときは、指標の名前の下に分母（「65歳以上人口 1,000 人あたり」）を薄く添える。
- **置き場所**：ふだんはポインタの右下に置く。地図の右端か下端からはみ出すときは、ポインタの左か上に置く。はみ出すかは、カードの最大の幅（288px）と高さの見込み（200px）で決め、カードの大きさは測らない。

## 背景地図の設定

`BasemapSettings.tsx` は、左上のパネルの単位の切り替えの右に歯車のボタンを置き、押すとその下に鉄道、道路、川のチェックボックス（DADS の Checkbox）を開く。
表示の値は app のストア（core の `AppState.basemap`）から受け取り、開閉だけを部品が持つ。
設定の見出し「背景地図」は、スクリーンリーダー向けの `legend` にだけ置く。

- **歯車**：名前は「背景地図の設定」で、`aria-expanded` と、開いているあいだは `aria-controls` を付ける。
- **開く**：最初のチェックボックス（鉄道）にフォーカスを移す。切り替えても設定は閉じない。
- **閉じる**：Esc と、歯車をもう一度押したときは、フォーカスを歯車に戻す。設定の外を押したときと、外へフォーカスが移ったとき（Tab で抜けたとき、Ctrl + K で場所の入力欄が開いたときなど）も閉じるが、押した先や移った先のフォーカスは奪わない。外を押したかは `pointerdown` を捕捉の段階で聞いて決めるので、地図をドラッグし始めたときも閉じる。
- **ホバーのカード**：設定はカードと別の要素で、ポインタを設定の上に移すと、地図の `mouseout` でカードは消える。設定を開いたまま地図の上でポインタを動かせば、カードは出る。

## DADS の部品

`dads/` には、デジタル庁デザインシステムの React のコード例（<https://github.com/digital-go-jp/design-system-example-components-react>、MIT）から、要る部品だけを取り込んだ（D18）。
取り込んだのはコミット `e637c68`（v2.7.0）のもので、著作権表示は `dads/LICENSE` に残した。
各ファイルの先頭に、出所と変更点を書いている。

コード例は Tailwind v3 で書かれているので、v4 との違いを直した。

- `outline` は v4 では幅 1px の指定を含み、`outline-4` と競合するので除いた。
- v4 のプリフライトはボタンに `cursor: pointer` を付けないので、ボタンに `cursor-pointer` を足した。
- 重要度の指定を、前置の `!` から後置の `!` に直した。
- CSS 変数を使う任意の値を、`top-[--x]` から v4 の `top-(--x)` の書き方に直した（Checkbox）。

Checkbox は、段階 7.5 で背景地図の設定のために、ほかの部品と同じコミットから取り込んだ。
DADS のコード例のとおり、フォーカスの枠は `focus-visible` ではなく `focus` で出すので、マウスで設定を開いたときも、最初のチェックボックスに枠が出る。

色は DADS のユーティリティ（`bg-key-900`、`text-solid-gray-800` など）を使う。
Tailwind の既定の色は、`styles.css` で DADS の色を読む前に消している（`reset-tailwind-colors.css`）ので、クラスを書いても色は付かない。

アイコンのうち、データの追加、表示の切り替え、削除のアイコンは、Figma のファイルの SVG のパスを `icons.tsx` に写した。
非表示の目のアイコンは Figma にないので、表示の目に斜線を足して作った。
背景地図の設定の歯車も Figma にないので、Material Symbols の線の太さ（1.5px）に似せて、8つの歯の輪郭と中心の丸を線で描いた。
